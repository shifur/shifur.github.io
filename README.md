# Shifur Rahman Shakil — Academic website

Responsive static academic portfolio. Six semantic HTML pages with shared CSS; no build process or JavaScript dependencies.

## Publish with GitHub Pages

All website files are in the root of this repository on `main`.

1. Open [Settings → Pages](https://github.com/shifur/shifur.github.io/settings/pages).
2. Under Build and deployment, choose **Deploy from a branch**.
3. Select `main` and `/ (root)`, then Save.
4. Once GitHub confirms successful deployment, visit https://shifur.github.io/.

This repository is named `shifur.github.io`, so it is the user-site repository for https://shifur.github.io/.

## Maintain

- `index.html`: biography, research highlights, selected publications and projects.
- `research.html`: research directions.
- `publications.html`: publications and technical reports.
- `projects.html`: all twelve selected projects.
- `experience.html`: academic and professional experience.
- `teaching.html`: teaching and mentoring.
- `style.css`: shared responsive styles.
- `.nojekyll`: static site configuration.

No private CV, headshot, internal research slides or figures are published. Two existing public project illustrations are linked from WordPress. The existing WordPress site is unchanged.
